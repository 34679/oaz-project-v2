# Океанский Альянс Защиты (ОАЗ)

Веб-сайт для некоммерческой организации по защите океанов и морских экосистем.

## Описание проекта

Сайт разработан для организации "Океанский Альянс Защиты" (ОАЗ) — независимой некоммерческой организации, работающей на стыке науки, права и общественных инициатив.

## Структура сайта

### Главная страница (index.html)
- Навигационное меню
- Hero-секция с названием организации
- Слайдер новостей с автоперелистыванием
- Блок "О нас"
- Блок "Наша миссия"
- Блок "Нам нужна ваша помощь" с кнопками
- Подвал с контактами
- **Динамическая статистика** (пожертвования и часы из БД)

### Проекты (projects.html)
- Список всех проектов организации
- Фильтрация по статусу (все, текущие, запланированные, завершенные)
- Карточки проектов с информацией:
  - Название
  - Количество участников (волонтеров и доноров)
  - Накопленная сумма / целевая сумма
  - Часы работы
  - Статус
  - Даты проведения
- Кнопки "Присоединиться" и "Задонатить"
- **Для администратора**: admin-projects.html с возможностью добавления и редактирования

### Детали проекта (project-detail.html)
- Полное описание проекта
- Изображение
- Информация о проекте
- Прогресс сбора средств
- Кнопки действий

### Каталог новостей (catalog.html)
- Три категории: Новости, Проделанная работа, Помощь
- Переключение между категориями через вкладки
- Свайп влево/вправо для мобильных устройств
- Карточки новостей из БД

### Страница карточки (card.html)
- Полное описание новости
- Секция комментариев (только для авторизованных)
